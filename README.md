# VolantSoft Website

Company website for VolantSoft — IT staffing and professional services firm based in Dallas, TX.

## Structure

- `index.html` — the full single-page site (services, clients, careers, contact)
- `assets/` — site images (hero, client logos, etc.)

## Viewing

Open `index.html` in any browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to host it.

## Clients featured

Gwinnett County · Commonwealth of Massachusetts · King County · Broward Sheriff's Office · State of Montana · Conifer Health Solutions
